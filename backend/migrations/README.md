# Database migrations

The backend uses PostgreSQL and Alembic. Set `DATABASE_URL` in `backend/.env`, then run these commands from `backend`:

```powershell
alembic upgrade head
alembic current
```

Create a migration after changing a SQLAlchemy model:

```powershell
alembic revision --autogenerate -m "describe the schema change"
alembic upgrade head
```

Review autogenerated revisions before committing them. Do not use `Base.metadata.create_all()` in application startup: migrations are the only place that changes the production schema.

For an existing database created before Alembic, back it up, inspect it against the initial revision, and run `alembic stamp 20260829_01` only if it already matches this baseline.
